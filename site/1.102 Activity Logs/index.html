Method Details

get_activity_logs()

get_activity_logs(board_id, user_ids, limit, page, from_date, to_date, column_ids, group_ids, item_ids)

Description: Retrieves activity logs from a specific board.

Arguments:

  • board_id (int): The ID of the board to retrieve activity logs from.
  • user_ids (list, optional): List of user IDs to filter logs.
  • limit (int, optional): Number of activity logs to retrieve (default: 25).
  • page (int, optional): Page number to retrieve, starts from 1 (default: 1).
  • from_date (str, optional): Start date in 'dd.mm.yyyy' format.
  • to_date (str, optional): End date in 'dd.mm.yyyy' format.
  • column_ids (list, optional): List of column IDs to filter logs.
  • group_ids (list, optional): List of group IDs to filter logs.
  • item_ids (list, optional): List of item IDs to filter logs.

Returns: A list of activity logs if successful. Returns None or an error message if the request fails.

Example: 

logs = monday.activity_logs.get_activity_logs(board_id=12345678, user_ids=[123456, 654321], group_ids=["new_group_1"], limit=25, from_date='01.01.2023', to_date='01.01.2025')
