## Method Details

## get_account_details()

`get_account_details()`

**Description:**
Retrieves details of the Monday.com account.

**Returns:**

A dictionary containing the account details, including:

- Account ID
- Name
- Logo URL
- Active members count
- Country code
- First day of the week
- Timeline weekend visibility setting
- Subscription tier
- Plan details
- Associated products
- Signup product kind

Returns `None` or an error message if the API call fails.

**Example:**

```python
account_details = monday.account.get_account_details()
```
