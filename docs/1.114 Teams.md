# Teams Methods

| Method Name                      | Method Type | Description                                    |
|----------------------------------|-------------|------------------------------------------------|
| `get_teams()`                    | Getter      | Retrieves a list of all teams.                 |
| `get_team_members(team_ids)`     | Getter      | Retrieves members of specified teams.          |

---

## Method Details

## get_teams() 
`get_teams()`

**Description:**
Retrieves a list of all teams, returning their names and IDs.

**Returns:**
- Dictionary of team IDs and their names. `None` or error response if the request fails.

**Example:**

```python
teams = monday.teams.get_teams()
```

---

## get_team_members() 
`get_team_members(team_ids)`

**Description:**
Retrieves the members of one or more specified teams.

**Arguments:**

- **team_ids** *(list of int)*: List of team IDs to retrieve members from.

**Returns:**
- Dictionary of team names with a list of their members (ID, name, and email). `None` or error response if the request 
fails.

**Example:**

```python
team_members = monday.teams.get_team_members([123456789, 987654321])
```
